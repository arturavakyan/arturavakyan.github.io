## 👨‍💻 About Me

I am an **Astrophysicist and Lead Software Developer** with 5+ years of experience in building complex data pipelines, machine learning models, and high-performance physical engines. 

I specialize in bridging the gap between raw astronomical Big Data and end-users by architecting robust, user-friendly scientific web portals and support systems. My passion lies in transitioning from pure academia to permanent infrastructure and software development for large-scale international scientific facilities.

## 🛠️ Key Software Products & Projects

Here are some of the main projects highlighted on my website:

### 1. [XRBcats: Science User Web Portal](http://astro.uni-tuebingen.de/~xrbcat/)
Architected and deployed a comprehensive, standardized relational database and public web portal for Galactic X-ray binaries. 
*   **Tech Focus:** Full-stack architecture, Data standardization, Web portals, providing FAIR data access to the global community.

### 2. [FREDDI (C++ Physical Engine)](https://github.com/hombit/freddi)
Co-developer of an open-source C++ physical engine for modeling accretion disc dynamics. 
*   **Tech Focus:** High-Performance Computing (HPC), C++, implicit finite-difference schemes, and tridiagonal matrix algorithms.

### 3. [Interactive 3D Galaxy Visualization](https://arturavakyan.github.io/assets/galaxy_3d_prior3.html)
An interactive, browser-based 3D visualization tool for astrophysical priors.
*   **Tech Focus:** UI/UX for science, Data Visualization, JavaScript, WebGL.

### 4. Big Data ML Pipelines (eROSITA)
Designed and implemented supervised ML pipelines to process, cross-match, and classify millions of X-ray sources against billion-row datasets (Gaia DR3, WISE).
*   **Tech Focus:** Python, `scikit-learn`, Random Forest, SMOTE, `pandas`.
