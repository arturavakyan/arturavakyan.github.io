About the 3D Galaxy Map

This interactive 3D application is designed for the visualization and exploration of High-Mass X-ray Binaries (HMXBs) within the Milky Way. It combines local catalog data with real-time queries to astronomical databases.

Visualization Features
  • Galactic Structure: Highly detailed 3D representation of the Milky Way's spiral arms (Norma-Outer, Scutum-Centaurus, Sagittarius-Carina, Perseus, Local, 3-kpc, and Spur) based on the BeSSeL survey (Reid et al. 2019).
  • Dynamic Environment: Features a generated background starfield, distant galaxies, and a galactic dust plane.
  • Key Reference Points: Quick focus toggles for the Sun (☉) and the Supermassive Black Hole at the Galactic Center (Sgr A*).
  • Uncertainty Visualization: Displays 3D "error bars" (whiskers) along the line of sight for sources with uncertain distance estimates.
Smart Search Engine

The map features a powerful search bar with auto-suggestions and cascading queries (Local Database → SIMBAD → VizieR):

  • By Name: Type any object name or alias (e.g., Cen X-3, Vela X-1).
  • By Gaia ID: Exact queries using the format Gaia DR3 [ID].
  • By Coordinates: Supports both ICRS and Galactic coordinates (e.g., 135.5 -40.5 or 16 17 04.4 -15 31 14.8).
  • Radius Customization: Adjust the coordinate search radius in arcseconds, arcminutes, or degrees.
Custom Distance Overrides

You can dynamically override the distance to any searched object using the @ syntax. The map will instantly project the source to the specified distance:

  • @8kpc or @8000pc — Places the source exactly at 8 kpc.
  • @12+4-5kpc — Places the source at 12 kpc and draws uncertainty whiskers spanning from 7 kpc to 16 kpc.
Database Integrations & Tools
  • Comprehensive Info Cards: Clicking a source reveals its Distance, Z-height, RA/Dec, Spectral Type, Mass, Pulse Period, and more.
  • External Links: Direct access to the object's page on SIMBAD, VizieR, and the XRBcats catalog.
  • 3DNh-tool Integration: A dedicated button copies the object's coordinates/parameters to your clipboard and opens the Tuebingen 3D NH-tool.
Navigation & Controls
  • Mouse Controls: Left-click and drag to rotate, scroll to zoom, right-click and drag to pan.
  • History: Use the Back ◀ and Forward ▶ buttons (or Alt + Left/Right Arrows) to navigate your recent searches.
  • Reset View: Double-click anywhere on the map, press the Esc key, or click the Reset button to return to the default overview.
